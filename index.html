Основне формулювання

У прямокутному трикутнику квадрат довжини гіпотенузи дорівнює сумі квадратів довжин катетів:

c² = a² + b²

Наслідки для обчислень

  • Знаходження гіпотенузи: c = √(a² + b²)
  • Знаходження катета: a = √(c² - b²)
  • Обернена теорема: якщо a² + b² = c², то трикутник прямокутний.
